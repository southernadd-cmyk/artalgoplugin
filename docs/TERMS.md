# ALGO/ART · Composition — Terms of Use

**Effective date:** 8 October 2026

ALGO/ART · Composition is a tool for generating compositional reference images using the original ALGO/ART algorithms in ChatGPT.

## How the tool works

The plugin creates deterministic geometric compositions and returns preview PNGs or a full-size reference PNG. ChatGPT's separate image-generation service, when available, may use that reference to produce a final artwork. The plugin itself does not guarantee that the final image will exactly reproduce every geometric placement or area of negative space.
